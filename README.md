# tidepool

Tidepool is a Foundry project built around **TidepoolHub** — an ERC-1155
token with a linear USDC price curve and buy/sell functions. Active
development happens on the `daily/YYYY-MM-DD` branches; Brandon reviews and
merges each day's work himself.

## Setup

Dependencies are installed (not vendored) via:

```sh
./scripts/bootstrap.sh
```

## Tests

```sh
forge test
```
